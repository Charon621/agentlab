# AgentLab 本地修复验收（2026-10-15）

在既有实现上完成安全、恢复与检索重放修复。本机 Python 回归 **92/92** 通过；另完成实际 LangGraph 60 单元离线计划、真实本机 HTTP 的 60 单元检索重放，以及两项目受控协议夹具联调。上述记录不代表真实云端模型质量。

## 已修复

- 测试导入应用前使用独立数据目录，禁用 dotenv 并清除继承凭证；外部连接被阻断。恢复子进程使用同一隔离规则。
- 多 owner 的历史环境凭证冲突不能被普通认领覆盖；原冲突会话可在模型页显式修复，保留非秘密审计。
- 联动 grant 在每次凭证解析时检查当前配置版本；撤销、过期和配置漂移均阻断后续调用。
- 删除任务改为可恢复归档。检查点、日志、调用账本与报告保留；从「研究历史 → 回收站 / 恢复任务」恢复。运行中任务仍需先停止。
- 隐藏面板遵从 hidden 属性；人工确认的计划和方向写入持久化检查点，刷新与恢复后可回读。
- 固定检索快照校验 SHA256，命中返回冻结证据，未命中只返回空结果，不联网回退。单、多架构使用相同快照和预算。

## 连续执行完整计划

```bash
.venv/Scripts/python.exe scripts/prepare_experiment.py --output examples/experiment_plan.json
.venv/Scripts/python.exe scripts/run_plan.py --plan examples/experiment_plan.json --output <新的输出目录>
```

默认只执行 Mock 工程验证。运行器按种子打乱题目配对块，保留块内 single/multi 交替次序；逐单元落盘。续跑使用相同参数加 `--resume`，计划、检索或源码漂移时拒绝续写。

通过本机 HTTP 执行完整计划：

```bash
.venv/Scripts/python.exe scripts/compare.py --base-url http://127.0.0.1:8811 --plan examples/experiment_plan.json --search-snapshot <固定检索快照.json> --output <新结果.json>
```

真实调用另需 `--execution-mode live --model-config-id <配置ID> --config-version <版本>` 和仅存内存的 `AGENTLAB_GRANT_TOKEN`。真实实验前须明确模型、样本、出站范围、请求及重试上限和预算。本轮未执行真实供应商调用，质量评分保持 `not_reviewed`。

## 验证与恢复

运行 `.venv/Scripts/python.exe -m pytest -q`。不要将历史测试数字当作当前结果。Windows 和 Ubuntu 的 CI 工作流已配置；本轮只验证本机 Windows，远端 CI 需推送后运行。

升级前保留工作树补丁与 SQLite 一致性备份；不要直接复制正在写入的 SQLite 主文件代替 backup。回退代码前先停止本项目服务，再在新目录恢复数据副本验证，不覆盖原数据。归档字段为增量迁移，不删除历史记录。API Key 与 grant 不进入备份或任务导出；服务重启后从网页补充凭证。
